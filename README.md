# ExamAI

اپلیکیشن اندرویدی «آزمون‌یار هوشمند» برای استخراج سؤال‌های آزمون، تحلیل آن‌ها بر اساس منابع درسی و نمایش پاسخ همراه با استناد.

## اجزای پروژه

این مخزن از دو بخش تشکیل شده است:

- اپلیکیشن اندروید مبتنی بر Kotlin و Jetpack Compose
- بک‌اند مبتنی بر Python و FastAPI

## ساخت APK با GitHub Actions

پس از قرار دادن همه فایل‌ها در مسیر صحیح:

1. مخزن را در GitHub باز کنید.
2. وارد تب **Actions** شوید.
3. گردش‌کار **Build Android APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. اجرای شاخه `main` را تأیید کنید.
6. منتظر بمانید تا علامت اجرای گردش‌کار سبز شود.
7. صفحه اجرای موفق را باز کنید.
8. در قسمت **Artifacts** فایل `ExamAI-debug-apk` را دانلود کنید.
9. فایل ZIP دانلودشده را استخراج کنید.
10. فایل `app-debug.apk` را روی دستگاه اندرویدی نصب کنید.

## تنظیم نشانی بک‌اند

اپلیکیشن برای تحلیل آزمون به بک‌اند نیاز دارد. در مخزن GitHub به مسیر زیر بروید:

`Settings → Secrets and variables → Actions`

سپس گزینه **New repository secret** را انتخاب کنید.

نام Secret:

`EXAMAI_BACKEND_URL`

مقدار آن باید نشانی عمومی و HTTPS بک‌اند باشد و در انتها `/` داشته باشد؛ برای نمونه:

`https://example.com/`

نشانی نمونه را با نشانی واقعی سرور خود جایگزین کنید.

## نکته مهم

بک‌اند Python داخل APK اجرا نمی‌شود و باید جداگانه روی یک سرور اینترنتی مستقر شود. ساخت موفق APK به معنی راه‌اندازی خودکار بک‌اند نیست.

## مسیر خروجی APK

پس از ساخت موفق، فایل APK در این مسیر تولید می‌شود:

`app/build/outputs/apk/debug/app-debug.apk`
