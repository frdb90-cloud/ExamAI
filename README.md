# ExamAI Offline

اپلیکیشن آفلاین اندروید برای پاسخ‌گویی پیشنهادی به آزمون‌های چهارگزینه‌ای براساس منابع درسی واردشده توسط کاربر.

## امکانات اصلی

- واردکردن منابع درسی از حافظه گوشی
- استخراج متن PDF و فایل متنی روی دستگاه
- انتخاب تصویر برگه آزمون
- استخراج متن تصویر با OCR روی دستگاه
- شناسایی سؤال و چهار گزینه
- جست‌وجوی پاسخ در منابع ذخیره‌شده
- نمایش گزینه پیشنهادی، میزان اطمینان و متن مرتبط منبع
- نگهداری اطلاعات در دیتابیس محلی
- عدم ارسال عکس‌ها و منابع به سرور

## حریم خصوصی و اتصال اینترنت

عملیات اصلی برنامه پس از نصب روی گوشی انجام می‌شود و برنامه برای تحلیل آزمون به بک‌اند، Render، API یا کلید سرویس هوش مصنوعی نیاز ندارد.

در اولین نصب ممکن است مؤلفه تشخیص متن ML Kit توسط سرویس‌های گوگل دریافت شود. پس از آماده‌شدن مؤلفه، OCR روی دستگاه اجرا می‌شود.

## ساخت APK در GitHub

1. تمام فایل‌ها را در مسیر تعیین‌شده مخزن قرار دهید.
2. وارد تب Actions شوید.
3. گردش‌کار Build Offline Android APK را انتخاب کنید.
4. روی Run workflow بزنید.
5. پس از موفقیت فرایند، فایل ExamAI-Offline-debug را از بخش Artifacts دانلود کنید.
6. فایل ZIP را استخراج کنید.
7. فایل app-debug.apk را روی گوشی نصب کنید.

## محدودیت پاسخ‌گویی

این نسخه براساس شباهت متن سؤال و گزینه‌ها با مطالب منابع پاسخ پیشنهاد می‌کند. برای پرسش‌هایی که پاسخ آن‌ها به‌صورت متنی در منابع وجود دارد مناسب‌تر است. دقت پاسخ در سؤال‌های محاسباتی، تصویری، نموداری یا بسیار استدلالی ممکن است کمتر باشد.
